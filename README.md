# Susik · 수식연습실

항을 터치해 수식을 바꾸고, 변형 이유를 한 줄씩 남기는 학습용 수식 작업실입니다. 본식 옆에 여러 보조 식을 두고 계산할 수 있습니다. 브라우저에서 실행하는 정적 웹앱이며, 수식을 풀이 서버로 전송하지 않습니다.

## 실행

Node.js 20 이상과 npm이 필요합니다. 개발·검증 환경은 Node.js 24입니다.

```sh
npm ci
npm test
npm run build
npm start
```

`http://localhost:8080`을 엽니다. `dist/`가 정적 사이트 배포 폴더입니다. 런타임 외부 CDN, API 키, 데이터베이스가 필요하지 않습니다. 소스 변경 후 `npm run build`로 해시 번들을 다시 생성하세요.

공개 서비스 주소는 `https://susik.app`입니다. 이 저장소는 외부 호스팅 전용이며 기존 Sites 프로젝트 설정이나 자격 증명을 포함하지 않습니다.

## Cloudflare Pages 배포

Cloudflare의 **Workers & Pages → Create application → Pages → Connect to Git**에서 `cranyoung-cpu/susik`을 연결합니다.

| 설정 | 값 |
|---|---|
| Production branch | `main` |
| Framework preset | `None` |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | 저장소 루트(비워 두기) |
| Node.js | `.node-version`의 `24` 사용 |

첫 배포 후 **Custom domains → Set up a domain**에서 `susik.app`을 연결합니다. 도메인의 DNS 영역과 Pages 프로젝트는 같은 Cloudflare 계정에 두세요. GitHub 저장소 연결과 도메인 등록은 Cloudflare에서 한 번 설정해야 합니다. 이후 `main`에 올리는 변경은 자동 배포됩니다.

빌드는 `https://susik.app` 기준 canonical·sitemap을 생성합니다. `main`은 검색 수집을 허용하고, Cloudflare의 다른 브랜치는 `noindex,nofollow`와 robots 차단을 적용합니다. 기존 도메인의 브라우저 저장 기록은 새 도메인으로 자동 이전되지 않습니다.


## 사용 흐름

1. 상단 **자유 수식 작성**에서 빈칸에 문자·지원 LaTeX를 쓰고 **새 풀이 시작**을 누릅니다. 본식 기록 맨 끝에 독립된 시작행을 추가하며 이전 풀이·보조 식·참조는 보존합니다. 새 풀이에는 이전 조건·가정·치환·제외·분기·논리문·연습 답과 결과를 가져오지 않습니다. 취소·닫기는 기록과 현재 줄·시트를 바꾸지 않습니다. 하단 **새 줄 / 새 줄 쓰기**는 현재 풀이에서 이어 쓰는 기존 입력입니다. **예제·연습·도움말·백업** 메뉴를 펼치면 시작 도구와 백업을 사용할 수 있으며 저장 상태와 실패 경고는 항상 메뉴 밖에 표시됩니다.
2. 전체 식을 누르면 **양변조작**, 항이나 괄호를 누르면 **항 변형** 도구가 열립니다.
3. **＋ 보조 식**으로 별도의 계산을 시작합니다. 본식·보조 식은 각자 기록과 현재 줄을 유지합니다.
4. 보조 식의 **결과 대입**은 등식 또는 계산 전후의 관계로 본식의 같은 부분을 대입합니다. 미리보기를 확인한 뒤 적용합니다. 직접 쓴 보조 식의 타당성이나 최종 해 전체를 자동 증명하지는 않습니다.
5. 입력 화면의 **입력 도움말 · 전용 계산**을 펼쳐 **행렬 / 미적분 / 연립식** 탭으로 전용 입력을 엽니다. 계산 과정은 보조 식으로 기록됩니다. 행렬·연립식은 여러 줄 붙여넣기도 가능합니다.
6. **복사**로 현재 수식의 문자·LaTeX 또는 본식과 보조 식 전체의 설명을 내보냅니다.

## 실제 지원 범위

| 분야 | 지원 | 범위·제한 |
|---|---|---|
| 수식 입력 | 다항식, 분수, 거듭제곱, sqrt/abs, 삼각·역삼각함수, ln/log/exp, e/π/i, 등식 | 2,000자·AST 220노드 이내. 모든 LaTeX 명령을 계산 문법으로 지원하지는 않음 |
| 항 변형 | 합·곱·거듭제곱 분해, 공통인수, 전개, 완전제곱, 나머지 남겨 묶기, 약분·통분 | 정확한 유리수·복소수 기초대수 범위. 규칙별로 지원 문자·차수 제한이 다름 |
| 방정식 | 양변 사칙연산, 이항, 조건과 0인 경우 보관 | 임의 방정식의 모든 해를 자동 판정하지 않음 |
| 부등식 | 단일 실수 다항식의 <, ≤, >, ≥; 같은 다항식 더하기·빼기, 0이 아닌 유리수 상수 곱하기·나누기 | 음수는 방향 반전. 0·문자식 곱하기/나누기, 연쇄 관계·함수·변수 분모는 보류. 조건 메모·양화사에서 부호를 추론하지 않음 |
| 지수·로그 | 법칙, 밑 바꾸기, 로그↔지수 방정식 변환 | 실수 로그 조건 유지. `log(x)`는 상용로그, `ln(x)`는 자연로그, `log(x,2)`는 밑 2 |
| 행렬 | 합·차·곱, 전치, 행렬식, 역행렬, 기약 행 사다리꼴과 행 연산 과정 | 1~4행·열. 유리수 실수부·허수부의 상수. 문자 성분·고유값·행렬 기호식은 미지원 |
| 일차 연립식 | 가우스–조르당 소거, 유일해·해 없음·무수히 많은 해, 자유변수 | 미지수 2~4개, 식 2~4개, 유리수 계수. 비선형 연립식은 미지원 |
| 미분 | 1~3차, 선택 변수에 대한 편미분, 곱·몫·연쇄법칙, 기본 함수 | 실수 함수, 삼각함수는 라디안. 조건을 기록하며 특이점의 별도 극한 판정은 하지 않음 |
| 적분 | 합·상수배·거듭제곱, 일차식 안쪽의 sin/cos/exp/ln/제곱근, 역수, 양수 상수 밑 지수함수 | 지원 기본형만 기호 적분. 부정적분 상수 보관. 유한 정적분의 끝값 차 계산. 일반 치환·부분적분·이상적분·수치적분은 미지원 |

행렬이나 적분 기호를 **표시할 수 있는 것**과 임의 식을 **계산·변형할 수 있는 것**은 다릅니다. 지원하지 않는 계산은 결과를 만들어 내지 않고 범위를 안내합니다. 부등식은 기기 자판으로 <, <=, >, >= 또는 ≤, ≥를 입력하고 기존 양변 조작에서 지원 연산을 적용합니다. 실수 범위 조건을 명시해 다음 행에 보존하며, 치환 적용·복원이나 보조 식 결과 대입은 아직 지원하지 않습니다. 그 밖의 범위는 상단 조건에 기록합니다. 조건이 기존 조건에서 따라오는지를 일반적으로 자동 증명하지 않습니다.

보조 식의 행렬·미적분 결과는 본식과 동치인 식으로 취급하지 않습니다. 연립식의 `x = 값` 같은 결과는 본식에 대입할 수 있으며, 행렬은 입력 고치기로 계속 계산합니다.

등식의 양변 조작은 저장된 치환 정의를 펼쳐 0인 분모·곱셈값·나눗셈값을 확인합니다. 제곱근 항이 정리되어 사라져도 정의역 안내를 다음 줄에 남기며, 실수 계산에서는 근호 안이 0 이상이어야 합니다. 로그 항이 없어져도 실수 로그의 진수 > 0, 밑 > 0·밑 ≠ 1 조건을 유지합니다. 잘못된 상수 진수·밑은 적용을 차단하고, 로그의 진수·밑에 중첩 함수·복소수·지원 밖 거듭제곱 등 정확히 확인할 수 없는 계산이 있으면 조작을 보류합니다. 파서가 원래 숫자를 반올림하는 경우에도 조작을 보류합니다. 조건 메모의 참·거짓이나 전체 풀이의 동치를 자동 증명하는 것은 아닙니다.

## 저장과 기록

- **백업 내려받기 / 백업 복원**으로 본식·보조 식·조건·치환·풀이 설명·연습 기록을 JSON 파일에 보관하고 복원합니다. 파일은 서버로 보내지 않습니다. 복원 전 줄 수를 확인하고 현재 작업장을 백업할 수 있으며, 복원 직후 취소할 수 있습니다. 최대 8MB이며 형식·버전·참조·자료형을 검사합니다.
- 저장 실패 안내는 성공할 때까지 계속 표시되며 파일 백업과 재시도를 제공합니다. 브라우저 저장 접근 자체가 차단되어도 작업실은 열립니다.
- 다른 탭이나 뒤로 가기로 돌아온 화면의 저장 기록이 다르면 덮어쓰기를 멈추고 안내합니다. **최신 기록 불러오기**는 자유수식 초안·커서·조건 설정을 유지합니다. 이전 화면의 실행 취소는 초기화하며, 저장된 풀이 줄은 유지합니다. 다른 입력창의 미저장 내용은 먼저 복사해 보관하고 닫아 주세요. 저장하지 못한 풀이가 남아 있으면 현재 화면 백업을 먼저 내려받아야 최신 기록을 불러옵니다.
- **처음이라면 · 사용 순서와 저장**에서 본식·보조 식·조건의 역할을 확인합니다. 직접 입력과 이전 버전에서 가져온 수동 풀이에는 **동치 미확인**을 표시하며 설명 포함 복사에도 유지합니다. 도구 변형은 전체 논증의 증명을 의미하지 않습니다.

- `susik-lab.workspace.v1`에 본식, 최대 20개 보조 식, 각 기록의 조건·치환·계산 입력을 저장합니다.
- 각 식의 기록은 최대 300줄이며 한 번에 24줄을 표시합니다. 브라우저 저장 공간이 부족하면 오류를 표시합니다.
- **되돌리기**는 최근 작업을 취소하고, **원상복귀**는 시작 식·조건·치환을 새 줄로 복원합니다. 기존 기록은 유지합니다.
- 다른 기기로 자동 동기화하지 않습니다. 브라우저 데이터를 지우면 기록도 지워집니다.
- 이전 버전의 composer/practice 저장 키는 삭제하지 않고 가능한 기록을 가져옵니다.
- 현재 UI에서는 사진 OCR, 광고, 분석 추적, 계정·서버 채점 기능을 실행하지 않습니다. 연습문제의 최종 답은 브라우저에서 문제별 기준으로 확인합니다. 풀이 서술·중간 단계와 삼각 일반해 집합의 동치·해의 누락은 자동 채점하지 않습니다.

`dist/`의 개별 JS/CSS는 편집 가능한 소스이며 `dist/assets/`는 생성된 번들입니다. 명시적으로 허용한 AST와 자체 규칙을 방문하며, 사용자 입력에 JavaScript `eval()`을 사용하지 않습니다. 수치 샘플의 일치를 일반 동치 증명으로 사용하지 않습니다.

## 검증과 UI 참고

자동 검증은 Node 테스트와 LinkeDOM 상호작용 검사, MathLive SSR 수식 렌더링 검사로 구성됩니다. 실제 휴대폰 브라우저의 배치·터치·시스템 키보드 동작은 별도 확인이 필요합니다.

저장 직전에 이 화면이 읽거나 마지막으로 저장한 스냅샷과 현재 저장값을 비교합니다. [Web Locks](https://developer.mozilla.org/en-US/docs/Web/API/Web_Locks_API)를 지원하는 브라우저에서는 탭들의 확인·변경·저장을 같은 잠금으로 순서대로 처리합니다. 미지원 환경에서도 저장 전 비교와 충돌 안내를 적용합니다. 서버나 추가 저장 키를 사용하지 않습니다.

입력 설계는 다음 공식 문서를 참고했습니다. 행렬은 행·열 크기와 칸 입력, 미적분은 식·변수·구간 분리, 입력칸은 하나의 공통 키패드를 사용합니다.

- [Desmos Matrix Calculator](https://help.desmos.com/hc/en-us/articles/4404851938445-Matrix-Calculator)
- [GeoGebra Integral](https://geogebra.github.io/docs/manual/en/commands/Integral/)
- [GeoGebra Solve](https://geogebra.github.io/docs/manual/en/commands/Solve/)
- [MathLive Virtual Keyboard](https://mathlive.io/mathfield/guides/virtual-keyboard/)

서드파티 배포물의 라이선스는 `dist/vendor/`와 생성 번들의 `LEGAL.txt`에 보관합니다. 프로젝트 자체의 공개 라이선스는 아직 정하지 않았습니다. 이전 구현 기록은 [docs/earlier-versions.md](docs/earlier-versions.md)에 있으며, 현재 지원 범위는 이 README를 기준으로 합니다.

## 향후 광고 슬롯

페이지 맨 아래, 푸터 다음에 `#footer-ad-slot`과 내부 `#footer-ad-content`를 준비했습니다. 현재는 `hidden` 상태이며 광고 요청·추적·빈 광고 공간이 없습니다. 풀이 도구와 분리된 일반 문서 흐름에 배치하며 기존 하단 도구의 여백을 유지합니다.

추후 광고를 연결할 때에는 광고가 설정된 배포에서만 최초 화면 표시 전에 `hidden`을 제거하고 내부 컨테이너에 넣으세요. 표시된 뒤에는 슬롯 높이를 바꾸거나 무응답을 이유로 접지 않아야 레이아웃 이동을 피할 수 있습니다. 현재 예약 높이는 모바일 100px, 넓은 화면 90px이며, 사용하는 광고 크기는 이 영역에 맞춰야 합니다. 사용 중 갑자기 슬롯을 열거나 조작 버튼 바로 옆에 광고를 붙이지 마세요. 슬롯에 클릭 이벤트를 달지 않으며 광고 표시는 항상 유지합니다. 실제 광고 제공업체 연동은 포함하지 않습니다.

## 조건·정의, 내 설명, 연습문제

- 기존 조건·치환 영역 안의 **기호·정의 추가**에서 최대 세 양화사를 순서대로 조립합니다. 변수와 ℝ/ℤ/ℚ/ℂ/ℕ₀/양의 실수 정의역을 선택하고 명제 및 자연어 뜻을 입력하면 괄호 범위와 순서를 유지한 표기·설명이 표시됩니다. ℕ₀는 0을 포함합니다.
- 실수 변수, 전칭·존재, 양화사 순서, 정수 인수·로그 정의의 템플릿을 제공합니다. 직접 기호 표기는 정의역·자연어 뜻을 함께 요구합니다. 각 기록은 가정·정의·주장으로 분류하고 편집·삭제할 수 있습니다. **표기 조립은 논리 파서나 증명기가 아닙니다.** 자유변수, 술어 의미, 명제의 진위는 자동 검증하지 않으며 이 기록을 계산 엔진에 검증된 가정으로 전달하지 않습니다.
- 각 풀이 줄의 **내 설명 쓰기/편집**에서 최대 4,000자의 자유 서술을 저장합니다. 돌아가기는 편집 취소이며, 저장 실패 시 초안을 유지합니다. 본식·보조 식의 기록 및 풀이 전체 복사에 포함되고 새 계산 줄에 중복 복사하지 않습니다. 저장됨과 수학적 검증 안 됨을 별도로 표시합니다.
- 기존 예제 13개, 삼각방정식 안내 예제 4개, 음수 나눗셈 부등식 안내 예제 1개, 조건·치환 안내 예제 1개에 더해 **연습문제 13개**를 제공합니다: 인수분해 3, 전개 2, 지수 3, 로그 3, 방정식 2. 문제와 원래 조건을 보며 기존 조작 도구·보조 식·서술을 사용할 수 있습니다. 답 확인은 정확한 유리수 계산, 최종 해 집합, 문제별 인수분해·전개 형식만 확인합니다. 중간 논증을 채점하거나 모든 입력식을 검증하지 않습니다. `correct`, `incorrect`, `unverified`를 구분하며 지원 밖 입력은 정답 또는 오답으로 단정하지 않습니다.
- 음의 지수 문제는 정수 분자·0이 아닌 정수 분모의 분수 형식을 요구하며 동치인 분수도 허용합니다. 이 연습에서 정의하지 않는 `0^0`·분모 0은 정답으로 처리하지 않습니다. 로그 정의역 밖의 값, 빠진 해, 해가 아닌 값, 미완성 인수분해·전개는 각각 안내합니다. 답 입력창에도 원래 문제·조건이 표시되고, 입력한 답이 마지막으로 확인한 답과 다르면 미확인 상태로 표시됩니다.
- 판정 결과의 검사 기준 버전이 없거나 현재 기준과 다르면 **재확인 필요**를 표시합니다. 이전 답·판정·풀이를 그대로 보관하고, 답 확인창의 **다시 확인**을 눌러야 새로 판정합니다. 화면 열기·새로고침·백업 복원은 자동 재채점하지 않습니다. 백업 형식은 version 1을 유지하며, 앞으로 답 판정 규칙·기준 답·정의역이 바뀌면 `PRACTICE_CRITERIA_VERSION`을 함께 올립니다.
- 미검증의 이유는 발생 지점의 오류 유형으로 구분합니다. 지원 밖 계산만 자동 확인 범위 밖으로 안내하며, 구문 오류·정의되지 않은 식·추가 조건 확인·예상하지 못한 처리 실패를 오답이나 검증 완료로 표시하지 않습니다. 기존 판정과 기준 버전은 유지하고, 새로 확인한 결과에만 선택적 `reason`을 함께 저장합니다.

- 조립식 편집은 저장된 양화사·명제로 원문 기호·정의역·자연어 설명을 정확히 재현할 수 있을 때만 조립 상태를 복원합니다. 옛 조립 기록도 일치하면 복원하며, 직접입력·알 수 없는 구조·원문과 다른 기록은 원문 직접입력으로 유지합니다. 완성된 조립식을 전체 기호로 보고 돌아올 수 있지만, 수정한 직접입력 원문을 임의로 조립식으로 해석하지 않습니다. 취소는 저장 내용을 바꾸지 않으며 백업 version 1을 유지합니다.
- 자유작성 등 작업 창의 취소·닫기·Esc는 진입 직전 도구의 펼침/접힘 상태와 실행 버튼의 초점을 복원합니다. 입력 종류 전환이나 임시 접기 뒤에도 원래 복귀 상태를 유지합니다. 구조 편집으로 복원할 수 없는 입력은 수학적 오류로 단정하지 않고 원문 직접 편집을 안내합니다.

### 정적 풀이 예제

`/learn/log-equation/`은 실수 로그 방정식 하나의 정의역·로그 정의·동치 변형·해 확인을 자바스크립트 없이 제공합니다. `scripts/log-example.mjs`에서 빌드하며 `/learn/` 및 사이트맵에서 찾을 수 있습니다. `/?practice=log-2`로 연결된 작업실은 자동으로 기존 풀이를 바꾸지 않습니다. ‘이 연습 시작’을 누르면 기존 연습 엔진으로 새 기록을 추가합니다. 최종 답 검사와 자유 서술의 검증 상태는 구분합니다.

`/learn/substitute/`은 `=` 관계와 `:=` 정의, 치환한 문자의 범위, 정의 저장과 적용의 차이를 설명합니다. `scripts/substitution-lesson.mjs`에서 빌드하며 예제 데이터는 `dist/substitution-example.js`와 공유합니다. `/?example=substitution-positive-domain`은 기존 예제 확인창만 열고, 명시적으로 시작해야 본식 끝에 독립된 풀이를 추가합니다. 관련 연습 `/?practice=roots-2`는 별도의 모든 실수 범위 문제입니다.

계산·채점·저장은 브라우저 안에서 수행하며 서버 채점, 계정, AI API, 원격 저장은 추가하지 않았습니다. 각 정적 예제는 해당 문제에 명시된 실수 범위의 풀이를 다룹니다.

- 계산기 키패드는 오른쪽의 사칙연산·등호·제곱근·거듭제곱·지우기 위치를 유지하며 왼쪽 숫자·문자·함수만 전환합니다. 지우기는 커서 앞 한 글자 또는 선택 영역을, AC는 전체 입력을 지웁니다. 자유 수식에서는 자체 키패드를 기본으로 사용하고 **기기 자판**을 선택해야 휴대폰 문자 입력을 엽니다. **수식 키패드**로 돌아오면 기기 자판을 닫고 초안과 커서를 유지합니다. PC 물리 키보드는 그대로 입력할 수 있습니다.
- 자유 작성 입력칸은 커서 바로 앞·뒤 괄호의 대응 짝을 강조합니다. 중첩 괄호도 해당 짝만 표시하며, 원문과 커서 위치를 그대로 유지합니다. 선택 영역이 있거나 짝을 찾지 못하면 강조를 끕니다.

- 각 줄의 **줄 메뉴 → 이 수식 삭제**는 선택한 이전 줄만 목록에서 숨깁니다. 현재 식은 보호하고 원본·부모 줄·보조 식 참조는 보존합니다. **풀이 관리 → 실행 취소** 또는 **삭제한 수식 → 복구**로 되돌릴 수 있으며, 새로고침·백업 후에도 원래 위치로 복구할 수 있습니다. 영구 삭제와 자동 일괄 삭제는 제공하지 않으며 보관 원본은 기존 300줄 한도에 포함됩니다.
- **보조 식 전체 삭제**는 이름과 전체 줄 수를 확인한 뒤 실행합니다. 취소·닫기는 기록을 바꾸지 않으며, 삭제해도 본식의 현재 줄과 다른 보조 식은 유지합니다. 저장에 실패하면 보조 식을 그대로 유지합니다. 전체 보조 식 삭제는 새로고침 전 **풀이 관리 → 실행 취소**로 되돌릴 수 있지만 **삭제한 수식**에는 남지 않습니다.

- **조건·치환 → 조건·치환 보드**에서 부등식·양화사·정의역과 `a := sin θ`, `a := cosθ`, `u := 2θ`를 입력할 수 있습니다. 본식/보조식과 적용할 줄을 표시하며, 조건·정의 저장은 수식을 바꾸지 않습니다. 실제 치환·복원은 별도 버튼으로 실행합니다. 기존 정의의 뜻을 덮어쓰거나 순환 정의를 만들 수 없습니다.
- 수식 작성 중 **입력 도움말 · 전용 계산 → 조건·치환 보드**는 해당 새 풀이/보조식/새 줄의 초안에만 설정합니다. 수식을 확정하기 전에는 기존 줄을 변경하지 않으며 취소한 초안은 다음 자유 작성에 유입되지 않습니다.
- 지원 밖 정의는 **기호 정의로만 기록**을 선택하고 정의역·자연어 뜻을 함께 작성하면 기존 기호 기록으로 보관합니다. 계산용 치환 목록에 넣거나 자동 검증하지 않습니다. 양화사 순서·술어를 구조적으로 쓰려면 기존 **기호·정의 추가** 편집기를 사용합니다.
- 삼각함수 풀이에서는 `θ ∈ ℝ`, 도(°) 단위, `k ∈ ℤ`, `−1 ≤ a ≤ 1`, `a²+b²=1` 등의 조건과 다른 풀이 경로를 보존할 수 있습니다. `sin²θ`와 `sin(2θ)`는 구분하며, `sinθ`로 나눌 때 기존 도구는 0이 아닌 조건과 0인 별도 경우를 남깁니다. 일반해의 주기·누락·집합 동치를 자동 판정하지 않습니다. `θ=120°k` 같은 다른 형태를 오답으로 판정하지 않으며, 해의 대입 확인을 모든 해의 증명으로 표시하지 않습니다.
- 문자 사이의 곱은 계산용 입력에서 `4*a*b`처럼 ×를 명시합니다. 기호·주장 기록에는 `4ab`를 포함한 원문 표기를 그대로 보관할 수 있습니다.

- **예제·연습·도움말·백업 → 예제로 시작하기** 앞쪽의 **삼각방정식 ①~④**에서 `2sin²θ−sinθ=0`, `2cos²θ−cosθ−1=0`, `2sin²θ−3sinθ+1=0`, `2sin(2θ)−1=0`을 시작할 수 있습니다. 원식과 `θ ∈ ℝ`, 도(°) 단위, `k ∈ ℤ`를 확인한 뒤 시작하면 본식 기록 끝에 독립된 풀이를 추가합니다. 확인창 취소는 데이터·현재 행·시트를 바꾸지 않습니다.
- **힌트 · 치환 안내**, 그 안의 **마지막 확인 힌트**, **정답 비교 안내 · 직접 확인**은 처음에는 접혀 있습니다. `a := cosθ`·`u := 2θ` 등은 선택 안내이며 자동으로 정의를 추가하거나 풀이를 덮어쓰지 않습니다. 예제 패널의 **조건·치환 보드 열기**에서 직접 기록하고 적용할 수 있습니다. 예제 연결은 풀이·보조식·원상복귀·백업 version 1에서 유지됩니다.
- 네 안내 예제는 기존 자동 채점 연습 13개와 구분합니다. ②의 `θ=120°k` 및 동치인 세 갈래 표기를 모두 안내하고, ③의 150° 가지 누락, ④의 각도와 주기를 함께 절반으로 나누는 이유를 정답 비교에서 설명합니다. 일반해 집합의 동치·완전성을 자동 판정하거나 유한 표본 검산을 증명으로 표시하지 않습니다.
