# 연습 풀이 줄 초안 복구 검토 · 2026-10-21

기준 main: `a873b56c0bdb91c011021701b1f6a9c810573457`. 기존 작업 트리는 깨끗했고, 원격 main과 일치했다.

## 재현 문제와 구현

기준 커밋을 별도 로컬 포트에서 Chromium으로 실행했다. `power-2` 연습 시작 → 풀이 줄 추가 → `sin(x+123` 입력 → 새로고침 → 풀이 줄 추가를 다시 열면 입력은 `3 ^ (-2)`로 돌아오고 복구 안내는 없었다. 기존 풀이 저장 문자열은 동일했다. 즉 미저장 수식만 실제 유실됐다. 독립 검토에서도 메모리 초안만 유지되는 점과 재부팅 손실을 확인했다.

본식 연습의 **풀이 줄 추가 → 수식 · LaTeX** 하나에만 복구를 추가했다. 수식 원문(최대 2,000자), 선택 범위·방향, 키패드 탭, 해당 현재 줄의 연결 정보와 시간만 별도 `sessionStorage` 슬롯에 보관한다. 마지막 보관에서 24시간 이내이고 현재 문제·줄 정보가 같으면 복구/버리기를 제안한다. 복구는 입력창만 열며 풀이·정답을 자동 저장하거나 판정하지 않는다. 잘못된 수식도 그대로 복구할 수 있다.

빈 입력·원식으로 되돌림·기록 완료·취소·닫기는 슬롯을 무효화한다. 새 문제·원상복귀 등 문맥 변경도 이전 초안을 연결하지 않는다. JSON·버전·크기·선택 범위·시간을 검증하고 저장소 오류를 잡는다. 노트 저장 실패 때에는 기존 문맥의 초안을 보존한다. 기존 풀이 저장 키·백업 version 1·복사·PNG·수학 엔진·채점 기준은 바꾸지 않는다.

## 독립 교차 검토 피드백

- 제안: 좁은 연습 입력 경로, 세션 보관, 명시적 복구, 원래 줄과 연결, 보드 조건 누락 방지. 모두 반영했다.
- 실제 재현 결함 1: 임시 슬롯 삭제만 실패할 때 버리기가 성공처럼 보인 뒤 재부팅에서 재등장. 빈 값 쓰기 대체를 추가했고, 삭제·쓰기 모두 실패하면 후보를 유지하며 실패를 알린다. 재검토 재현과 회귀 검사 통과.
- 실제 재현 결함 2: 새 문제로 바뀐 뒤 슬롯 무효화가 모두 실패하면 보이지 않는 후보가 새 입력을 차단. 문맥이 다른 메모리 후보를 분리해 새 입력을 허용하고 실패 안내를 유지하도록 수정했다. 재검토 재현과 회귀 검사 통과.
- 보드·전용 계산으로 이동할 때 무효화 실패면 이동을 보류한다. 조건 없는 이전 텍스트를 잘못 복구시키지 않는다.
- 독립 최종 검토에서 배포 차단 결함 없음. 최종 추가 1개 이전 전용 검사 12개를 독립 실행해 모두 통과했다.

## 제안으로 남긴 범위와 한계

자유 작성·보조식·최종 답·서술·직접 변형·조건 보드·전용 계산의 복구, 브라우저/탭 종료 후 복원, 입력 undo 전체 이력 보관은 구현하지 않았다. 조건 보드·전용 계산으로 이동한 초안은 돌아와도 복구 대상에서 제외된다고 표시한다. 임시 슬롯을 삭제도 덮어쓰기도 못하는 브라우저 상태에서는 무효화 성공을 보장하지 않으며 실패 안내 후 저장 사용이 가능해지면 다시 버려야 한다. 새 문제에는 문맥이 다른 초안을 적용하지 않는다.

기존 공개 사이트 프록시 403은 우회하거나 재시도하지 않았다. 배포 성공은 기존 GitHub Workers Builds 검사로 확인하고, 공개 화면 직접 확인 여부는 완료 보고에서 구분한다.
