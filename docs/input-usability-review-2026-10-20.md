## 재현하여 수정한 두 항목

1. 작은 화면의 답 입력창 가림: Chromium 320×568에서 `/?practice=power-2` → 이 연습 시작 → 답 입력·확인 → 본문 맨 아래까지 스크롤. 기존 답 입력칸의 y=48.95~92.95가 본문 가시 영역 y=124.53~498 밖으로 나간다. 키패드가 보여도 입력과 커서를 볼 수 없다. 답 입력칸에도 기존 자유 수식 입력과 같은 sticky 동작을 적용했다. 수정 후 입력칸 y=150.67~194.67로 가시 영역 안에 남는다. 하단 답 확인 버튼은 기존 고정 영역을 유지한다.
2. 지원 밖 계산의 복구 경로 누락: 자유 수식에 `foo(x)` 또는 `integral(x)`를 입력하면 범위 제한 문장만 표시됐다. 기존 거절 이유에 지원 문법 예시, 입력 도움말·전용 계산, 기호 정의 기록 경로를 덧붙였다. 원문을 바꾸거나 자동 허용하지 않으며, 빈 함수·괄호 오류·정의역·정밀도 등 별도 오류 안내는 우선 유지한다.
